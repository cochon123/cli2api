How it works

One command. Same clients.

Coding CLIs already handle login, quotas, and tool loops — they just speak terminal. cli2api gives benchmarks, agents, and SDKs one authenticated local API.

Wrap your command

cli2api run --adapter auto -- … starts an ephemeral gateway, injects client variables, and cleans up.

Or keep it running

serve --port 0 --json returns one readiness object with URLs, token, adapter, health, model, and workspace.

Keep your client

Use OpenAI Chat or Responses, Anthropic Messages, or OpenRouter aliases — including streaming, tools, and sessions.

Local by design

Not a cloud proxy

Your CLI credentials stay on your machine. Adapters start in a fresh empty directory with restrictive policies, including a cli2api-owned deny-by-default OpenCode agent. Processes still run as your user; this is not an OS sandbox.

  • Loopback only — binds to 127.0.0.1 by default
  • Bearer token required — no open endpoints
  • Fresh empty workspace — project files require explicit --project or --cwd
  • No open CORS — built for SDKs and scripts, not browsers

Install

Up in thirty seconds

Install once — check available CLIs, then wrap any environment-aware client without copying a token or port. 

# install and inspect available CLIs
$ npm i -g @cochon123/cli2api
$ cli2api doctor --json

# temporary authenticated gateway; auto-select a ready CLI
$ cli2api run --adapter auto -- node my-agent.mjs
